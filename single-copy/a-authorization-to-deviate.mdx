## **<u>Part 2: PAPPG Translated Into Plain English</u>**

### a. Authorization to Deviate

<Tip>
  Plain English: If you have a legitimate reason you can't follow standard NSF proposal preparation rules (page limits, formatting requirements, content requirements, etc.), you can request a formal **deviation authorization** before submitting.
</Tip>

<Danger>
  Deviations are **not granted by reviewers or after submission.** You must request and receive written authorization **before** submitting the non-conforming proposal.
</Danger>

#### When you might need a deviation

<Check>
  Common scenarios:

  - Page limits (especially Project Description \>15 pages)
  - Required sections you cannot provide
  - Special formatting needs (e.g., for accessibility)
  - Solicitation-specific deviations
</Check>

#### Process

<Note>
  1. Contact the cognizant NSF Program Officer
  2. Get a written deviation authorization
  3. **Include the authorization with the proposal as a single-copy document**
  4. Reference the deviation in your cover letter
</Note>

<Warning>
  Submitting a deviating proposal without prior written authorization = return without review. No exceptions.
</Warning>
